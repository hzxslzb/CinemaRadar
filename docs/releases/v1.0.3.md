# CinemaRadar 1.0.3 · 场次提醒更清晰

本次发布版本为 **1.0.3，构建号 4**，提供 Android 和 macOS（Apple Silicon / Intel）安装包。

## 本版更新

- 系统通知与应用内新场次提醒同步增加中文周几。
- 顶部提醒新增展开/收起按钮：收起时左右滑动浏览，展开后上下滚动查看更多场次信息。
- 展开状态显示日期、时间、语言、版本、影厅和购票状态，并保留快速选座跳转。
- 关闭仅隐藏当前提醒批次，下一批新增场次仍会再次显示。
- Android 构建配置更新到 SDK 36、Gradle 8.9。

保留影院模糊搜索、城市/行政区筛选、影片订阅、IMAX/Dolby 筛选、浅色/深色主题、自定义后台刷新间隔和猫眼/淘票票入口。

## 下载

| 文件 | 内容 |
| --- | --- |
| `CinemaRadar-1.0.3+4.apk` | Android 7.0 / API 24 及以上 |
| `CinemaRadar-1.0.3+4.zip` | macOS 10.15 及以上，arm64 / x86_64 双架构 |
| `CinemaRadar-1.0.3+4-android-macos.zip` | 上述两端安装包合集 |
| `SHA256SUMS-1.0.3+4.txt` | 三个安装文件的 SHA-256 校验清单 |

Android 包使用开发调试证书签名；macOS 包采用 ad-hoc 签名、未经过 Apple 公证。macOS 登录项管理需 macOS 13 及以上。本次没有 HarmonyOS HAP。

这是项目的首次 GitHub Release，安装包复用此前交付的 `1.0.3+4` 二进制；本次整理并公开完整源码、使用说明、截图、构建步骤、更新记录和 CI。

## 提醒与购票说明

Android 后台周期受系统调度影响，最短按 15 分钟处理；macOS 需要应用进程仍在运行，主动退出或休眠期间不会检查。各设备独立运行，订阅不自动同步。

购票功能跳转票务平台继续选座购买；淘票票需重新确认其平台场次。排片接口可能变更或限流，最终排片和订单信息以票务平台为准。
